# VenueEasy Bookings

i was make a website on (Hall booking Management) and our website name is VenueEasy
Client/User Flow
Home → Login/Register → Search Halls → Filter Halls → View Hall → Check Availability → Select Date/Time → Select Services → Cost → Booking → Payment → Booking Confirmation → My Bookings → Review/Rating

Hall Owner Flow
Login → Owner Dashboard → Add/Manage Hall → Set Availability → Receive Booking → Accept/Reject Booking → Manage Bookings → View Reviews

this is our workflow
